# 旧・連続運転モード（Ver.0.1）

Ver.0.1 のメインだった「建設速度で連鎖の波から逃げ切る連続運転」のコード一式です。
Ver.0.2 ではメインゲームから外し、将来の **チャレンジモード** 用としてここに保存しています（現在のビルドには含まれません）。

- 完全な動作版はタグ `v0.1` で復元できます：`git checkout v0.1`
- 主なファイル：`game.js`（連鎖とルール）、`field.js`（固定周回コースのドミノ）、`route.js`、`facilities.js`、`ui.js`
- 復活させる場合は、Ver.0.2 の物理ドミノ (`src/core/dominoes.js`) に合わせて連鎖部分を置き換える必要があります。
