# Ver.0.6 安定化（建設・物流・経路・事故後の復旧）— 調査と検証

ブランチ：`dev/v0.6`。新しい勢力・アイテム・見た目の追加はしていません。「小人はドミノの狭いすき間を通れない」は維持しています。

## 1. どこで時間を失っていたか（計測）

ゲーム内に計測（`src/game/metrics.js`、デバッグの `__dbg.metrics()`）を入れ、乱数の種を固定した自動プレイで記録しました。

記録した項目：建設・倒れたままの枚数の推移／仕事がなくて待っている時間／遊び・休憩の時間／役目ごとの移動距離／経路が見つからない理由／補給できない回数／作業場所を仲間がふさいだ回数／復旧の仕事を受けてから着くまでの時間／倒れてから起こされるまでの時間／遊びから仕事に戻るまでの時間／いま立ち往生している人数とその継続時間／倒れた原因（ネズミなどのいたずら・連鎖・人の体・置いた直後・起こした直後）。

### 見つかった原因

| 種類 | 何が起きていたか | 区別 |
|---|---|---|
| 目的地のすぐそばで着けない | 倒れたドミノのそばなどで、体が当たって少しずつ向きを変え続け、1mも離れていない所で何十分もうろうろ（仕事を受けてから着くまで最大3861秒） | **動けるが着けない** |
| 足元から動けない | 倒れたドミノの山や、おもちゃ箱のそばで「立っているマス」が見つからず経路が引けない（失敗2993回） | **動けない** |
| 3枚以上が互いに重なって倒れる | 2枚までしかほどけず、起こせるドミノがなくなって永久に放置 | **割り振りの欠陥** |
| 大事故の立て直しで全員が建設をやめる | 立て直しが終わらないうちに次の事故が来て、建設が止まる | **割り振りの欠陥** |
| 資材箱が先頭から遠い | 運搬担当が4人そろわないと箱が動かないので、建設担当が毎回遠くまで取りに行く | **遠回り（物流）** |
| 遊んでいる人が仕事に気づかない計測の誤り | 計測上の「戻るまでの時間」が積み上がる誤り（修正） | — |
| 原因の内訳（ステージ1） | 倒れたドミノの6〜7割はネズミ・ボールのいたずらとその連鎖。人の体が当たって倒れたのは1〜3枚程度 | ゲームの難しさ（事故そのものは残す） |

`findBuildJob()` は「行けないマスも含めて14件」で探索を打ち切っていたため、行けるマスを見逃すことがありました。

## 2. 直したこと

- **到着の判定**：3秒ほとんど位置が変わらないとき、目的地まで2以内なら「手が届く所に着いた」、遠ければ12秒で仕事を手放して別の人へ。体がドミノにめり込んだら、まずそのドミノから離れる方向へ一歩出る。
- **足元から動けない**：周りの倒れたドミノを、しゃがんで起こす・拾って道を作る。経路の出発点は少し離れた通れるマスから探す。
- **仕事の割り振り**：建設は行けるマスを30件まで比較（行けないマスは数えない）。たどり着けなかった人には同じ仕事を30秒回さず、行ける別の人に任せる。マスから遠く飛ばされたドミノは拾って片付ける。倒れたドミノが別のマスの上に寝ていたら、どけてから起こす（3枚以上の重なりでも止まらない）。
- **大事故の立て直し**：建設中の事故で25枚以上倒れると、設計主任（いなければ先輩）が「建設班も立て直しに回ってくれ！」と声をかけ、建設担当も全員が手前（連鎖をさえぎる所）から分担して起こす（最大5分）。8枚以上が45秒以上放置されたときは、近くの建設担当1人だけが手伝い、ほかは建設を続ける。本番で倒れたドミノは「事故」に数えない。
- **物流**：資材箱が先頭から遠いとき、運搬担当が何人でも、倉庫・資材箱からドミノを小分けに運んで「前線のドミノの山」を作る。建設担当はここからも取る（資材箱を4人で担ぐ仕組みはそのまま）。
- **通路**：突然出現する自動歩道橋をやめた。たどり着けない仕事があるときだけ、建設担当が「踏み板（基本の通路）」を実際に組み立てる（ステージで6本まで。回りこめる所には作らない）。遠回りがひどい所の歩道橋は、エリート建築士 Lv.1 以上が施工（4本まで）。
- **生活と仕事**：遊んでいる人は、急ぎの仕事（立て直し・資材切れ）ではすぐ切り上げる。それ以外は設計主任や仲間が呼びに来る（主任がいないステージ1では5秒、ステージ2では15秒で自分で気づく）。手の空いた仲間が、昼寝の人を起こしに行く。

### そのほか
- 通れないすき間：狭い列は端を回る／すき間は通る／倒れたドミノはよける／囲まれた所は待つ／歩道橋は渡る — 普通の小人の接触は0。横着な小人は体が当たって押し（29フレーム）、1枚が物理で倒れた。
- 資材箱：3人では25秒たっても動かず、4人目が来ると集まって担ぎ、運んで下ろした。
- 生活：キャッチボール・ハンモックで寝る→起こされる・設計主任のお誘い・おかえりを確認。
- 全連鎖（全部並べて倒す）：ステージ1 889/889、ステージ2（立体交差）1339/1339、ステージ2（線路の撤去）1339/1339。
