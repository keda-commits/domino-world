## 第1段階：動作と不快感

### 8. 観客ボイスの削除
- `jingles.js` の `crowd()`、`audio.js` の `crowdAww()` を削除。`updateAccidentReaction()` は事故の枚数を数えるだけにして、音と「おぉ〜……あぁ〜……」「ブー！」の表示を出さない。
- 確認：900秒の建設プレイ（事故10回）で、呼ばれた音は place / click / squeak / drop / pick / punch / success / checkpoint / bell / start だけ。`crowdAww` は存在しない。該当の文字表示は0回。

### 1. 資材箱
- 自分では動かない（`Crate.update()` の自動追従を削除）。
- 運搬担当が近くに4人そろうと、四隅について「せーのっ！」で持ち上げ、一番遅い人の速さで歩き、着いたら下ろす。
- 1人でも転ぶ・つかまれる・逃げると、残りの人が止まって「止まれ〜！ ゆっくり下ろすぞ」と下ろす。
- 4人未満のときは動かない（倉庫→資材箱の小分けの配達はこれまでどおり）。プレイヤーのドラッグは今まで通り（置いた直後90秒は担がない）。
- 運ぶ途中、箱と4人の体の位置でドミノとの接触を毎フレーム確かめ、当たるなら止まって道を探し直す。
- 位置は毎回保存（以前のセーブの「先頭についていく箱」も最後の位置に置く）。
- 確認：3人のまま25秒 → 位置は変わらず（46）。4人目が来ると集合→持ち上げ→運搬→到着（47）。

### 7. 小人がドミノをすり抜けない
- 小人の体の半径 0.25（肩幅 0.5）。ドミノどうしのすき間は 0.6 − 0.15 = 0.45 なので通れない。
- 経路探索：ドミノの実際の形（向き・幅・厚み、倒れていれば寝た形）を体の半径だけ太らせて書き込む。列の「またぎ」（高いコストで通れた仕組み）を廃止。
- 移動中：毎フレーム、実際の位置で体（3段の球）とドミノの箱の重なりを調べ、普通の小人は当たる手前で止まる・向きを変える。
- 道がなければ待つ（6秒で仕事を手放して考え直す）。確率で倒れる処理（またぎ事故・直進時の衝突）を削除。
- 横着な小人（なまけ度が高い人がときどき）だけ無理やり横切り、体が当たったドミノを、めり込んだ量に応じた力で押す。倒れるかどうかは物理まかせ。慌てて逃げる人も、よけきれないときだけ押す。
- 「同じ範囲か」を範囲番号で先に判定して、行けない所のA*を回さない（負荷対策）。A*に「調べ済み」の印を入れて、同じマスを何度も調べないようにした（以前からの無駄で、長い道が見つからない原因にもなっていた）。
- 列で区切られて行けない仕事ができたら、設計主任が歩道橋を架ける（最大24本。プレイヤーの歩道橋の数には含めない）。同じ所でひどい遠回りが続くときも架ける。
- 作業は列の「自分がいる側」から行う（向こう側へ回りこまない）。置こうとするマスに仲間が立っていたら、声をかけて横へよけてもらう。
- 確認（`passtest`）：狭い列→端を回る（接触0）／すき間→通る／倒れたドミノ→よける／歩道橋→渡る／囲まれた所→待つ（接触0）／横着な小人→体が当たって3回押し、1枚が物理で倒れた（70）。

## 第2段階：生活感と見た目

### 2. 小人の村と、相手のいる行動
- 丸い目印と看板だけだった待機所を、小人サイズの村に：積み木の家（戸口4.75cm相当）、ボタンの花の庭、鉛筆の柱のハンモック、糸巻きのテーブルと積み木のベンチ、ボール、役目ごとの道具置き場。床はハンカチをつないだ四角いパッチワーク（40〜44）。
- 置き場所は部屋の隅と家具の脚元。
- 少数のイベントとして管理（全員どうしを毎フレーム調べない）：
  - **キャッチボール**：2人。投げる→飛ぶ→受ける→投げ返す。取りそこねると拾いに走る（「ドンマイ！」）。片方が抜けるともう片方が片付ける（41）。
  - **ハンモック**：昼寝の人は自分では起きにくい。仕事ができると、村の仲間か設計主任が起こしに来る（「おーい、起きて！ 仕事だよ」→「はっ！ いま行く！」）（42・43）。
  - **お誘い**：遊んでいる人は仕事ができてもすぐには気づかない（設計主任がいるステージ2では15秒、いないステージ1では5秒で自分で気づく）。設計主任が村に来て「みんな、仕事だ！」→ 振り向いて敬礼・返事 → 走って仕事へ（44）。
  - **おかえり**：ベンチの人が、戻ってきた仲間を迎える。ベンチ2人はおしゃべり。

### 3. 獲得アイテムの実物展示
- 獲得できる道具（ステージ1・2）：作業ブーツ・運搬カゴ・水平器・四つ葉・歩道橋・バリケード・自動遮断ゲート（その他の人員・設備は本人・本体が現れる）。以前はすべて色違いの箱だった。
- 専用の模型で、効き目が分かる小さな情景にした：赤い長靴と足あと／ドミノがいっぱいの背負いかご／まっすぐ立った2枚のドミノに当てた水平器／鉢植えの四つ葉ときらきら／ドミノの列をまたぐ橋と渡る小人／ミニカーを止める柵／列の切れ目に下りる遮断機。
- 棚は「持っているだけで効く道具」（中段）と「置いて使う・自動で働く道具」（下段）に分け、札は絵文字＋ひとこと（45）。
- 歩道橋は2案（A：橋だけ／B：列と渡る小人つき）を作り、使い方まで分かるBを採用。

### 4. 設計主任
- ふだん：建設の先頭へ行って図面を広げ、先を指さす（ときどき「次はあっちだ！」→ 近くの建設担当が「了解！」）。できた所を見て回る（48）。
- 資材箱が空に近い →「資材が足りない！ 運搬班、頼む！」→ 運搬担当が返事して急ぐ。
- 列の向こうへ行けずに困っている人 →「ここは通れないな。迂回してくれ！」→「わかりました、回ります！」。
- 線路とぶつかったとき：建設担当が「線路があって進めない…」と困る → 主任が現場へ → 図面を見る → 「エリート、ここに階段を架けられるか？」／「撤去班、レールを外してくれ！」→ 班が「任せてください！」「了解、外します！」と返事して走る → 完成すると建設担当が「やった、進めるぞ！」。
- 本番前：「本番前に階段を点検してくれ！」→ 建築士「点検よし！」。
- せりふは9秒に1回まで。ふだんは仕草で見せる。

## 第3段階：鉄道との押し引き

### 6. ぽっぽ線の路線計画（2本だけ。無限には延ばさない）
- 保線主任（赤い帽子）が計画を調べ、保線係が工事用トロッコから青いレールを1本ずつ運んで敷く。予定線は床の青い点線、終点には「◯◯駅 線路 n/N本」の看板（50）。
- **廊下線（第1の衝突）**：ドミノとぶつかる所で、保線係と建設担当がけんか（「ここはぽっぽ線の線路を通すんだ！」「ドミノが先に並べてるんだよ！」）→ 設計主任「ドミノの建設を優先させてもらう！」→ ぽっぽ線は手前に「廊下口駅」を作って迂回し開業（51・52）。先に線路が横切っていた場合は、撤去班がレールを外し、ぽっぽ線が迂回する。
- **手前線（第2の衝突・複線）**：大きな交差。エリート建築士 Lv.2 なら立体交差（階段）→ 下を複線が通って「手前駅」まで開業（53〜55）。Lv.2 未満なら手前で終点。
- どちらも最後は開業し、支線を小さな列車が往復。外された本線のレールは、これまでどおり本番のあと保線係が戻しに来る。
- 確認：手前線まで含めた自動プレイで、ステージ2の1339枚の連鎖がクリア（鉄道側の工事でドミノが進めなくなることはなかった）。
