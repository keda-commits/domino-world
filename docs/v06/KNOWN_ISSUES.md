# Ver.0.6 開発プレビュー：既知の問題

開発中のプレビューです。正式公開版（Ver.0.5系）とは別のURL・別のセーブで動きます。

## 進行・難しさ
- **ステージ1が自動プレイで8回中1回クリアできなかった**（ゲーム内9000秒以内）。建設は進んでいたが、ネズミのいたずらによる事故が多く（235回）、一本の連鎖がそろわなかった。同じ条件の再実行ではクリア。
- **ネズミによる事故が多い**。ステージ1で倒れるドミノの6〜7割はネズミ・ボールのいたずらとその連鎖。ストッパー設置係がいないと連鎖が長くなる。
- **クリアまでの時間のばらつきが大きい**。自動プレイでステージ1は788〜3913秒、ステージ2は1066〜2345秒（ゲーム内時間）。
- **建設は以前の版より少し遅い**。小人がドミノの列をまたげず回りこむため（意図した仕様）。

## 小人の動き
- 混み合った所や急なカーブのそばで、小人が少しの間（数秒〜1分程度）立ち止まることがある。
- まれに、ドミノの列に囲まれた所へ行けない仕事があると、建設担当が「踏み板」を組み立てるまで待つ。

## 表示
- ステージ2の線路・駅・小人の村などは新しく作ったもので、見た目の調整は途中。
- 吹き出しのせりふが重なって読みにくいことがある。

## セーブ
- プレビューのセーブは、正式版とは別の名前で保存される（同じブラウザでも正式版のセーブは読まない・書かない）。
- 「ステージ1から遊ぶ」と「ステージ2から試す」も、それぞれ別のセーブ。
- 開発中のため、プレビューを更新するとセーブを引き継げなくなる可能性がある。
