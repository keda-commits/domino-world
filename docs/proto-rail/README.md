# 試作：鉄道勢力との共存と衝突（ステージ2用）

本編とは別のページです（本編のセーブには触れません）。本編ステージ2への統合は評価後に行います。

- 公開URL：https://keda-commits.github.io/domino-world/proto-rail.html （`?s=A` / `?s=B` / `?s=C` で試作を選択）
- コード：`src/proto/rail/`（`track.js` 線路網・レールの撤去と破砕・修理 / `trains.js` 列車 / `people.js` 人 / `world.js` 鉄道の暮らしと3つの攻略方法 / `main.js` 画面）
- 開発ブランチ：`proto/railway`

## 舞台
楕円の線路（ぽっぽ鉄道）を2本の列車（あおば号・ひばり号）が走り、駅A・駅Bに停まり、ときどき車庫で点検する。
ドミノのコース（左のスタート台 → 右のゴールのベル）が、駅Aの直線（西の線路）を横切る。この「交差地点」をどう越えるかを選ぶ。

## 3つの方法
| 方法 | 操作 | 良いところ | 困るところ |
|---|---|---|---|
| 🚦 交通整理 | ポイントSを迂回線へ／駅Aの信号を赤に → 線路の上にもドミノを並べる → 倒す → 片付け | 資材ゼロ・速い | 時間制限（50秒→38→26、3回目のあとはしばらく断られる）、駅Aのお客さんが待つ、片付けないと列車が止まって抗議 |
| 🏗 ドミノ階段 | エリート建築士 Lv.2 が材木22本で立体交差を建てる → 階段にドミノ → 倒す | 線路を壊さない・列車が喜ぶ（友好度アップ）・一度建てれば何度でも使える | 最初は時間と材木がかかる |
| ⛏ レール撤去 | レールはがし隊が交差地点のレールを外す → すき間にドミノ → 修理班が戻す前に倒す | 確実に道ができる | 列車は後退・迂回、友好度が下がる、修理班がドミノをどかしに来る |
| 🔨 破砕ハンマー | 交差地点のレールを砕く | 撤去より速く、修理も長引く（窓が広い） | 衝撃でまわりのドミノが倒れる（立て直しが必要）、友好度が大きく下がる |

## 検証の結果（自動プレイ、同じ条件で各5回）
| 方法 | 連鎖成功 | 準備できるまで | 資材 | 列車の遅れ | 友好度 |
|---|---|---|---|---|---|
| 交通整理 | 5/5 | 69秒 | ドミノ32 | 13秒 | −6（2回目以降はもっと下がる） |
| ドミノ階段 | 5/5（毎回50/50枚） | 約120秒（2日目以降は約62秒） | ドミノ29＋材木22 | 約1秒 | +6〜7 |
| レール撤去 | 5/5 | 85秒 | ドミノ32 | 45〜91秒 | −13 |
| 破砕ハンマー | 5/5 | 76秒 | ドミノ32（衝撃で7枚倒れ、立て直し） | 約24秒 | −21 |

ドミノ階段の物理（上り段差0.25・下り段差0.2/間隔0.8）は、置き方の誤差（±4cm・±3°）をつけた別の検証でも 30/30 成功。
